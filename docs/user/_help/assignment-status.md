The sample browser marks each sample's assignment status with a tag badge:
**green** for a sample with a completed assignment run of its own, the **accent
colour** for one served from the batch ledger without a run of its own, and
**faint** for one with nothing assigned yet. Hovering a green badge names the
engine that produced the run, its version and when it ran; every badge also
says how many of the sample's peaks carry an assignment in the batch ledger.
Assign the sample for a ledger of its own.
