When the engine's winner is not the right answer, you can assign a peak
yourself: **use this** on any close alternative in the peak inspector, or the
**hand button** on a re-search result to put a composition you found onto the
selected peak. The row is marked as assigned by hand, and the assignment it
replaced becomes the peak's first close alternative &mdash; so the same control
puts it back. Its confidence tier is recalculated from the new assignment's own
fit under the run's thresholds, and the calibrated probability of the
assignment it replaced is not carried over: that number described a different
formula. Isotopologue satellites of the replaced formula become unassigned,
because they were the same compound seen through a heavy atom. A hand
assignment lives in the run you made it in &mdash; **re-assigning the sample
recomputes the ledger from the data and replaces it** &mdash; so record a
verification if you want the judgment to survive.
