**Why this tier** lists what the run found about the row, in its own words. The
evidence sets the highest tier a row can reach, and a row short of the top band
says so first, with its numbers. Every rule after it can only lower the tier:
each names what capped the row at *candidate* &mdash; a radical neutral, rivals
the evidence left standing, an ion another neutral explains as well through
another channel, a line a neighbour's isotope pattern already predicts &mdash;
or what the row kept its tier on. A down arrow marks every reason that holds the
tier down, and an isotopologue lists its M0's reasons beneath its own.

**Same ion, read another way** lists the other neutrals this ion reads as
through the run's other channels. No mass or isotope pattern tells those
readings apart; a second channel can, and so can the sample showing one of
the molecules far more strongly than the other.

A row assigned by hand, a run imported from another engine and a run made
before Mascope recorded reasons list none.
