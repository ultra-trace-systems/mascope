Any assignment can be verified by hand: **confirm** it, **reject** it, or mark
it **unsure**, with an optional note. Confirming also asks for the level of
evidence behind the judgment &mdash; from a reference standard, MS/MS or an
orthogonal technique down to the isotope/adduct pattern or a visual check.
A confirmation also says what that evidence showed, which sets the
identification level it states, from 1 to 4 with the scale's letter: a
reference standard with an independent line beside it is level 1, without
one 2b. It can name the **structure** it identifies; one at level 1, 2 or a
3 naming a candidate must, and one MS/MS loss names a class instead (3b).
Rejecting on a reference standard refutes the confirmation it replaces.
Rejecting is a first-class answer, not a lesser one: confirmed and rejected
assignments together form the labelled record that future confidence
calibration is fit on. Verdicts attach to the peak, formula and ionization
mechanism rather than to one run, so they carry over when the sample is
re-assigned. One verdict covers a whole compound: judging it from any of its
isotopologue peaks records a single verdict, shown on all of them.

The **to verify** chip at the end of the ledger's tier strip counts the
assignments worth a verdict next and shows only them, in the order to ask:
first any verdict a later run read differently, then the rows near a tier
edge where the instrument has few verdicts so far, with random spot checks
between them. The queue shows no probability: judge the data, not a number.
