# Guides

Task-oriented how-tos, one task per page. Each guide links to
[Concepts](../concepts/index.md) instead of re-explaining the domain model.

- [Import data files](import-files.md) — upload raw instrument files and process
  them into samples in a batch.
- [Build a target collection and run matching](target-collections.md) — define
  the compounds to look for and score every sample against them.
- [Reference compound lists](reference-lists.md) — turn a published peak list
  or an in-house standards table into reference data that names the formulas
  peak assignment finds.
- [Two-factor authentication](two-factor.md) — protect your account with a
  second sign-in step, and know the way back in if the phone is lost.
