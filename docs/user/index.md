# Mascope

Mascope is a platform for analysing high-resolution mass spectrometry data:
import instrument files, browse samples and batches, run targeted matching,
and explore results in the web UI or via the Python SDK.

## Citing Mascope

If you use Mascope in your research, please cite the accompanying paper:

> Shcherbinin, A., Shen, J., Kausiala, O., et al. (2026). Networked Open-Source
> Infrastructure for Scalable Analysis of Chemical Ionization Mass Spectrometry
> Data. *ChemRxiv*. <https://doi.org/10.26434/chemrxiv.15005713/v1>

Full author list and machine-readable metadata are in
[`CITATION.cff`](https://github.com/ultra-trace-systems/mascope/blob/master/CITATION.cff)
(GitHub's "Cite this repository" button).
