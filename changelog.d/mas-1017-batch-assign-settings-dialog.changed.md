- **Assign sample opens on the batch's settings.** The per-sample launcher used to
  open on each user's own remembered settings, shared with the composition search.
  It now opens on the settings of the sample's batch every time, and a change made
  there is that one run's, recorded in the run and not remembered. Settings the
  batch saved that the dialog does not show, such as its tier bands, go into the
  run as well. The composition search keeps its own remembered m/z precision and
  formula range, and resolves an empty field with the batch's chemistry profile
  and context; a profile or context remembered from the old launcher is dropped.
