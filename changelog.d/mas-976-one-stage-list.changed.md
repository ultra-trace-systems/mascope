- **Every way a sample's peaks are assigned runs the same stages.** An
  assignment run, the ingest fold into the batch ledger, the batch's *Search
  untargeted*, the measurement of a batch decision on each sample (the
  search's, *Detect series*' and an import's), and a person's choice by hand
  or with *Use this* on a batch peak now go through one declared list of
  stages, from reading the sample's chemistry to keeping the result. An
  assignment run's output is unchanged. The batch ledger's tiers move: a
  peak the batch search reads or measures, a series or an import measures,
  or the ingest fold assigns now holds the tier an assignment run of its
  sample gives the same reading, the tiering rules' caps included, where it
  used to take its fit's band alone. A lone faint reading is held at
  *candidate* (*one peak only*) in each sample, as a run holds it.
