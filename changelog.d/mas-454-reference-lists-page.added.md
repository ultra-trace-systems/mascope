- **Settings shows the reference lists a deployment has loaded.**
  A Reference lists button under Settings, Data, opens a read-only list of
  every loaded list: its label, version, licence, polarity, radical
  allowance, window, species count and load date. Opening a row pages
  through its species with name, formula, mass and DOI. A list the licence
  gate leaves out is marked as not matched. Any signed-in user can open it.
