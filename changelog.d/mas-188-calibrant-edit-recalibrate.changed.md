- **Editing a calibration collection asks for a recalibration.** Changing the
  compounds of a collection an ionization mode calibrates on now marks the
  batches of that mode's files "recalibrate", not "rematch", as pointing the
  mode at another collection does, so their status icon offers to
  re-calibrate them. A collection used only for matching still marks its
  batches for rematching. The calibration column marks a TOF file fitted on
  an older version of its calibration collection in amber.
