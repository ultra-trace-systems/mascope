- **A pinned formula can now say one functional group (3b) or its one
  plausible structure (2b).** A peak at identification level 4a reads 3b
  where the adduct it was read through says a class of molecule, from a class
  table each reagent profile carries (a nitrate reagent's deprotonation: "an
  acid of this formula"), and 2b where a cited reference list marks its
  formula as having one plausible structure, such as trifluoroacetic acid.
  The evidence line names the class or the structure, the list and the work
  each entry cites; a peak that earns both reads 2b and names the class. A
  list species gains an optional `one_structure` mark, a citation with its DOI
  or ISBN, which the list checks hold to a named species listed once. The
  shipped profiles and lists carry no entries yet, so no peak reads 3b or 2b
  until they do. A 4a peak's lift now reads "a context list for the run's
  chemistry; MS/MS". Runs record level rules version 3.
