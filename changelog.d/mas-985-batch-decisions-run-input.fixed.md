- **A sample assigned again keeps what its batch decided about it.** A
  sample's run now reads every decision the batch stages made about it, not
  only the known species and the series. A rung of a reagent ion's water
  ladder that the batch passed in the stretch of acquisition the sample was
  acquired in is claimed as the reagent's ion, in a sample assigned again and
  in one folded in for the first time alike; a sample acquired outside every
  stretch the ladder measured claims none. A listed compound the batch
  decided present is committed on its peak at candidate, the decision named
  among the row's tier reasons, where the run read the peak another way or
  not at all. A row the batch stripped as another row's isotope line is read
  as that row's line before the run judges it. Until now a sample assigned
  again dropped all three, and its ledger disagreed with the batch's until
  the batch steps ran again. A decoy run claims the source ions and the
  listed compounds as its control does, and reads no strip and no series.
  Each run records which version of each batch stage it read
  (`config.batch_decisions`).
