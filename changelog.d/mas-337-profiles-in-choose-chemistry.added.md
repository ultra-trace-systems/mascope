- **The shipped chemistry profiles are offered from the first start.**
  Choose chemistry in Raw files lists the chemistries Mascope ships first,
  under **Profiles**, and the server's own ionization modes under
  **Advanced**. A fresh server's first file is processed after one click,
  with no mode, token or collection made by hand. The settings button in Raw
  files is now **Chemistry**: it opens on the profiles, each marked as
  shipped, with the calibrants it ships, how many files it has routed and
  when the newest was acquired. The server's own modes, the filename tokens,
  the mechanisms and pointing a profile at a collection of your own are under
  **Advanced**, where a profile's row edits only its collections. A file
  bound to a profile names it in its status: "Bound to the profile 'Bromide,
  negative' (-) as chosen by hand."
