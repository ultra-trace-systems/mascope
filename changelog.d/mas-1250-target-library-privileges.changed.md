- **A compound only your target library names keeps its peak, not its word.**
  The library is yours to write and can hold anything, so naming a compound
  there no longer counts as a second observation of it. Such a row now
  helps measure the run's calibration, and escapes the distance cap, only
  where an isotope line of it tracks its mass error. On one peak with no
  second line, no second channel and no series it is held at candidate
  (*one peak only*), and it no longer carries the *on a list* reason. On an
  assigned neighbour's isotope line it is read as that line. It still shows
  its match, and still keeps its peak against the search's rivals, the
  source's ladders and the batch's claims. A compound a reference list
  names too is treated as the list's. Tiering rules version 18.
