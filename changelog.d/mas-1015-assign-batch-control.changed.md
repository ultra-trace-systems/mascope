- **The nine batch-stage buttons are gone.** *Rebuild batch ledger*, *Search untargeted*,
  *Detect series* and the other per-stage buttons are replaced by *Assign batch*, which
  runs the stages in their fixed order as one pass. Starting the pass at one stage moves
  to *Advanced › Run from a stage* in its menu, shown with the new setting *Show
  assignment stages* (off by default). The batch's untargeted search now runs on the
  settings its last run on the batch recorded. The per-sample *Assign peaks* is now
  *Assign sample*.
