- **Assign batch's Details and Run history replace the batch run selector.**
  **Details**, beside the batch's assignment status, shows the pass the
  batch stands on: its stages under the four phases, each done, running
  with its share done, failed with its error, out of date with why, waiting
  or not run, a one-line result for each finished stage, the change the
  pass made to the tier counts, and the settings it ran under. **Run
  history** names each run as a person meets it: *Assignment*,
  *Assignment from a stage (Detect series)*, a stage's own name for a pass
  its API route started, *Import*, *Rebuild* or *Folded samples*. Picking an
  earlier run shows its ledger read-only, and the bar then says *Viewing run
  #N · read-only* with **Back to current**.
