- **Edit a batch's assignment settings in the app.** *Assignment settings…* in the
  *Assign batch* menu, and *Change settings* in its Details, open *Edit assignment
  settings*: the batch's own chemistry profile and context, m/z precision, formula
  range, peak ceiling, intensity threshold and alternatives kept, which every pass of
  the batch runs on. *Save* writes them onto the batch and starts nothing; the batch
  then reads behind, *Assignment settings changed since the last assignment*. A
  viewer sees them read-only.
