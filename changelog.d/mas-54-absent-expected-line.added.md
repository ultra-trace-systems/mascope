- **A peak assignment whose isotope pattern predicts a line the spectrum should
  show, and does not hold, is held at candidate.** Every committed formula is
  asked, whoever named it; a hand assignment is asked when it is made, at the
  threshold and window its run asked the run's own rows at. A peak assigned by
  hand as one of a compound's isotopologues is not asked, since the lines are
  read from the compound's main one. A line is expected
  where the fit score counts it missing, from the signal-to-noise threshold the
  run measured for the file (3 where it measured none, or 10% of the main line
  on a peak with no signal-to-noise), and looked for within the run's matching
  window. The new reason *expected line absent* names the line, its predicted
  share and the share from which the run expected lines. No second ionization
  channel lifts it: a bromide reading whose 81Br line is missing no longer stays
  assigned because another channel saw the molecule. A line where only an
  artifact's peak sits, or beyond the first or last peak of the spectrum, is not
  tested, and on a TOF a bromine or chlorine reading must show its own M+2 line.
  The peak inspector's isotopologue table lists the lines that were not found
  under the found ones, and the spectrum draws them as empty circles at their
  predicted heights. Tiering rule set 11; runs made before it are unchanged
  until run again (`docs/user/how-it-works/peak-assignment.md`, *Why a row
  holds its tier*).
