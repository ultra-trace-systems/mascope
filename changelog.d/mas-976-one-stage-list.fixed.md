- **A batch pin is asked whether its isotope lines are there.** *Use this*
  on a batch peak is judged as an assignment by hand on one sample is: a line
  the pinned formula predicts that the sample's spectrum lacks holds the pin's
  reading at *candidate* in that sample, and the measurement shown before the
  pin says so. A sample is asked at the threshold and window its assignment
  run asked its own rows' lines at, so one no run has read, such as a sample
  only folded into the batch ledger at ingest, is asked no line.

- **The batch's untargeted search reads chlorine and bromine from their twin
  line**, as an assignment run does, and sets aside the source's reagent
  lines and the detector's ringing before it searches.

- **The ingest fold reads a labelled reagent's lines at the purity of the
  sample's ionization setup**, not the element's default, as a run of the
  sample does.

- **A decoy run searches under its control's chemistry context.** A decoy of
  a run on *Auto* reads the context the batch or dataset named when its
  control ran, so renaming it in between no longer puts the decoy under
  another context; one whose reagent profile or context would still differ
  is refused.

- **The peak inspector's close alternatives are measured through every
  channel the row's run searched**, the secondary channels it opened
  included, so a formula that fits the peak only through an opened channel
  is placed instead of reading *could not be placed*.
